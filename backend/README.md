# JBook Backend API

Backend API JBook dibangun dengan Django dan Django Ninja. Deployment production menggunakan PythonAnywhere dengan konfigurasi WSGI manual; panduannya tersedia di [panduan deployment](../docs/guides/testing-deployment.md).

Untuk setup lokal, ikuti [panduan setup backend](../docs/guides/backend-setup.md).

Untuk gambaran modul backend dan penilaian penerapan SOLID saat ini, lihat [arsitektur backend](../docs/architecture/backend.md).
